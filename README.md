# sleepgenius07.github.io
艾宾浩斯复习日程表

-##功能
-用户将每天学习的内容在输入框里填入，网站自动根据艾宾浩斯遗忘曲线在日程表里分配复习任务，
本网站已经部署，**不用魔法**直接在浏览器中输入链接即可使用该网站

-*网站链接*
https://sleepgenius07.github.io/

-本链接在手机上打开之后是空表，可自己编辑，别的支持者打开不会看到别人的日程计划，
编辑完成之后再次打开，会有**今日复习摘要**自动弹出


-额外设计：

-1.日历上用彩色圆点标示每天的状态（已学/待复习/已完成/逾期）
-2.复习项按来源日期分组，显示第几轮复习和当前记忆保持率
-3.顶部有今日待复习提醒和统计面板
-4.每条学习记录下方可直接点击跳转到对应复习日期
-5.底部附记忆曲线可视化图示
